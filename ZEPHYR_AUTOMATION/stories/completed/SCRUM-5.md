## Story

User story
- As a User, when I want to login to the DashBoard of the OrangeHRM Demo Page, I want to securely access the HR management system so that I can perform my tasks.
Context
This user story is focused on testing the login feature of the OrangeHRM Demo Page. It aims to ensure that users can access the HR management system securely.
Acceptance Criteria
- User can log in successfully with valid username and password.
- System prevents login with invalid credentials and displays an error message ("Invalid credentials").
- System enforces mandatory fields — login fails if username or password is left blank.
- Password field masks input characters (shown as dots/asterisks).
- "Forgot your password?" link redirects user to the password recovery page.
- System handles case sensitivity correctly — login succeeds even if username does not match the stored case format.
